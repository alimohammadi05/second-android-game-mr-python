# Mr. Python 🐍🎓

A lightweight, educational 2D grid-based classic Snake game implemented in **Godot Engine 4** using **GDScript**[cite: 1]. 

---

## 💡 Educational Value & Architecture
This project is engineered as an open-source learning resource for foundational computer science and game development concepts[cite: 1]:
* **Grid-Based Movement Logic:** Demonstrates discrete coordinate mapping and directional input matrix calculations[cite: 1].
* **Dynamic Difficulty Scaling:** Implements algorithmic time-step adjustments (`TIME_STEP` reduction per score milestone) to dynamically scale game speed[cite: 1].
* **Persistent Configuration Management:** Utilizes Godot's built-in `ConfigFile` class for local data serialization and state persistence (`user://` path handling)[cite: 1].
* **Modular Code Structure:** Clean separation of game loop, scoring mechanics, and configuration management within standalone GDScript nodes[cite: 1].

---

**🎮 How to Play**

* Go to the **Releases** section of the repository.
* Download the **APK** file and install it on your device.
* Launch the game and guide Mr. Python using directional inputs to consume items, increase your score, and survive the accelerating speed curve!
